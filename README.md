# Прокси Список

> 70 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-craftsmanstage.github.io-256a9d)](https://craftsmanstage.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@MTProxy4free-2aabee)](https://t.me/MTProxy4free)

## Что внутри

- `70` проверенных прокси-серверов MTProxy: наши серверы Lite64 + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://craftsmanstage.github.io/](https://craftsmanstage.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
